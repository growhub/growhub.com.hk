# Case study content template

実績ページは、確認可能な事実だけを使って作成する。公開前に顧客名・ロゴ・画面・数値の掲載許可を確認する。

## 必須情報

- プロジェクト名（匿名の場合は業種＋サービス種別）
- 対応言語（en / zh-hk / ja）
- 顧客または対象業種
- 抱えていた課題
- GrowHubの担当範囲
- 制作・開発期間
- 提供した成果物
- 使用技術
- 公開年月
- 公開可能な画面画像（alt文も用意）

## 成果・根拠

- 導入前の状態
- 導入後の状態
- 公開可能な定量値
- 数値の計測期間と計測方法
- 顧客コメント（原文・氏名・役職・掲載許可）

定量値が公開できない場合は、「手作業だった工程を一つの画面に集約」など、検証可能な具体的変化を書く。

## 推奨ページ構成

1. 一文要約
2. 課題
3. プロトタイプで検証したこと
4. 実装内容と担当範囲
5. 技術的な判断
6. 成果
7. 画面・写真
8. 顧客コメント
9. 関連サービス
10. 問い合わせ

## SEO・構造化データ

- 言語ごとに固有のtitle・descriptionを作る
- `datePublished`と`dateModified`を実日付で設定する
- 執筆者・監修者がいる場合は実名とプロフィールを紐づける
- `Article`または内容に合う`CreativeWork`を使用する
- `BreadcrumbList`でホーム、実績一覧、実績詳細を接続する
